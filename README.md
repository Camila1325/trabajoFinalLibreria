# React Library App

Academic React project developed as part of a university course, focused on practicing component-based architecture, state management, and basic application structure.

# Features
- Component-based UI using React
- Organized folder structure for components, pages, and data
- Rendering dynamic data from JavaScript files
- Basic navigation between sections
- Simple UI styling with CSS
- Reusable components (navbar, product/list views)

# Tech Stack
- React
- JavaScript
- HTML5
- CSS

# Project Context
This project was built during my university studies to strengthen my understanding of:
- React fundamentals
- Component separation and reusability
- Handling and displaying structured data
- Basic frontend architecture

# What I Learned
- How to structure a React project for scalability
- Passing data through props and managing component logic
- Improving code readability and maintainability
- Working with modular JavaScript files

# Notes
This is an academic project intended to demonstrate React fundamentals and learning progress. Future improvements could include better state management, improved UI, and backend integration.
